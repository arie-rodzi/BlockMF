# BlockMF: Blockchain Microfinance Analytics Platform

BlockMF is a Streamlit-based research prototype for transparent microfinance and social capital analytics. It supports synthetic Malaysia–Maldives borrower datasets, decision scoring, blockchain-style transaction records, repayment analytics, fraud/risk indicators, and country comparison dashboards.

## Run
```bash
pip install -r requirements.txt
streamlit run app/main.py
```

## Main modules
- Synthetic borrower data generator
- Social capital and financial eligibility scoring
- Blockchain-style immutable ledger simulation
- Country comparison analytics: Malaysia vs Maldives
- Explainable decision output

## SoftwareX positioning
This prototype is designed as an open-source, reproducible software platform for blockchain-enabled microfinance decision support and analytics.
